# Lotus CRM - Quản Lý Đơn Hàng Thông Minh (AI)

Ứng dụng quản lý đơn hàng theo phong cách Kanban dành riêng cho Lotus Paint, tích hợp AI để tự động đọc và bóc tách thông tin từ ảnh chụp báo giá.

## 🚀 Tính năng chính
- **Quy trình Kanban chuyên nghiệp:** 6 bước từ Báo giá đến Hoàn tất.
- **Tự động hoá bằng AI (Gemini):** Kéo thả ảnh báo giá, AI tự điền tên khách, SĐT, địa chỉ và số tiền.
- **Báo cáo tài chính:** Tổng hợp doanh thu, công nợ thời gian thực.
- **Lọc và tìm kiếm:** Tìm kiếm theo khách hàng hoặc thời gian (tháng hiện tại/tháng trước).

## 🛠 Hướng dẫn triển khai lên Vercel (Online)

1. **GitHub:** Tạo một repository mới trên GitHub và đẩy mã nguồn này lên.
2. **Vercel:** Truy cập [vercel.com](https://vercel.com), kết nối với repo GitHub vừa tạo.
3. **Deploy:** Nhấn nút Deploy. Vercel sẽ tự động cấp cho bạn một đường link online.

## ⚙️ Cấu hình AI
Sau khi mở ứng dụng, nhấn vào biểu tượng ⚙️ (Cài đặt) và dán mã **Google Gemini API Key** của bạn vào. 
Lấy mã miễn phí tại: [Google AI Studio](https://aistudio.google.com/app/apikey)
